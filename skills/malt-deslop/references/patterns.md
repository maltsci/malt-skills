# Writing patterns that often read as AI-generated

These patterns are not forbidden forms. People use them too. Treat them as a problem when they recur close together, replace real reasoning, or add theatrical weight without information.

Rewrite by removing the scaffold and retaining the claim, evidence, and consequence.

## 1. False contrast

A model often introduces a shallow position only to overturn it with a supposedly deeper one. The rejected position may be one nobody held.

| Pattern | Revision direction |
| --- | --- |
| “It is not A, but B.” | State B directly. If a comparison matters, specify why A fails. |
| “This is not X. This is Y.” | Name the result or mechanism without the theatrical renaming. |
| “The real issue is not …; it is …” | State the actual issue, then support it. |
| “X has never been about Y; it is about Z.” | Remove the absolute claim unless it can be justified. |
| “真正的 X 从来不是 Y，而是 Z” | Write the concrete point and the reason; do not manufacture a binary. |
| “这不是 X，这是 Y” | Keep the supported claim and explain its basis. |

> Original: “This is not procrastination. This is risk.”
>
> Revision: “The unresolved risk is already delaying the schedule.”

## 2. Fake dialogue and presenter voice

Text can imitate conversation or announce a lesson instead of making its point.

| Pattern | Revision direction |
| --- | --- |
| “But here is the question.” | Name the problem directly. |
| “What is the deeper logic behind this?” | State the reason. |
| “You think that is all?” | Delete it. Use a factual transition if needed. |
| “Let’s break this down.” / “I will explain it simply.” | Begin with the explanation. |
| “The key point is coming.” | Delete it and make the next sentence useful. |
| “你以为这就完了？” / “重点来了，让我解释一下” | Delete the presenter cue; write the next point. |
| “先说结论” / “一次性讲透” / “掰开揉碎” | Put the conclusion first, then explain it. |

> Original: “But here is the question: what is the deeper logic? It is human nature.”
>
> Revision: “The incentive is the problem: reporting bad news carries no reward, so people postpone it.”

## 3. Unearned time shifts and revelations

Time contrast and scenes of realization work only when they establish a real change.

| Pattern | Revision direction |
| --- | --- |
| “In the past …; now …” | Give dates, events, or measurable changes; otherwise remove it. |
| “Then I suddenly realized …” | State the realization or the evidence that caused it. |
| “Reality slapped everyone in the face.” | Identify who predicted what, and what disproved it. |
| “That post/video made me understand everything.” | Cite the source if it matters; otherwise begin with the content. |
| “那一刻，我突然明白……” | Write the discovery and its evidence. |

Do not remove a scene merely because it contains looking, pausing, or thinking. Keep it when it carries time, character, or new information; cut it when it is a reusable transition with no job.

## 4. Decorative symmetry and fixed-size lists

Balanced clauses and three-item lists can look polished while hiding an absent decision.

| Pattern | Revision direction |
| --- | --- |
| “Not only X, but also Y.” | Remove the weaker half, then add a concrete consequence if needed. |
| “Both X and Y.” | Explain the trade-off when both are genuinely required. |
| “From X to Y.” | Give the range a boundary and a purpose. |
| “Faster, cheaper, smarter.” | Keep only the benefits that are evidenced. |
| “不是……不是……更不是……” | Keep the precise negation, or state the affirmative claim. |
| “既要……也要……” / “不仅……更……” | Clarify priorities and costs instead of claiming every benefit. |

> Original: “It is not laziness, not incompetence, and not a lack of effort. The underlying method is wrong.”
>
> Revision: “The method is wrong. More effort only adds time to the wrong direction.”

## 5. Manufactured alarm and applause

Do not ask the reader to feel a reaction that the text has not earned.

| Pattern | Revision direction |
| --- | --- |
| “This should make everyone shudder.” | Explain the concrete risk, loss, or affected group. |
| “More painfully …” / “The shocking truth is …” | State the next fact without announcing an emotion. |
| “This is the key.” / “Everyone overlooks this.” | Usually delete it; make the evidence carry the importance. |
| “后背发凉” / “头皮发麻” / “更扎心的是” | Replace with a specific consequence. |
| “这才是关键” / “大家都忽略了” | Delete unless the text establishes why. |

> Original: “More painfully, this leaves everyone with chills.”
>
> Revision: “The contract has no exit clause. If the vendor delays, the client can only wait.”

## 6. Overworked punctuation and labels

Punctuation is legitimate. The problem is repeated use as a substitute for structure.

- Replace em dashes used to stage a false contrast or dramatic fragment with a sentence that makes the relation clear.
- Keep quotation marks for quotations, terms under discussion, or genuine ambiguity; do not use them to make ordinary words look conceptual.
- Use colons when the following material completes or enumerates the preceding clause; do not use a colon as a default transition.
- Avoid inventing labels such as an “A–B–C framework” when the steps can be named directly.
- Do not remove a single purposeful dash, quotation mark, or colon merely because it appears in an AI-writing catalog.

## 7. Empty metaphor, borrowed analogy, and clipped coolness

| Pattern | Revision direction |
| --- | --- |
| “It is a scalpel, not a hammer.” | Describe what it does differently. |
| “It is the Excel of AI agents.” | Explain the workflow it replaces or enables. |
| “Fast. Simple. No fluff.” | Keep the one claim worth making and support it. |
| “It can be done in five to ten minutes.” | State a duration only when measured or clearly qualified. |
| “它是 AI agent 里的 Excel” | Name the saved step rather than borrowing a category. |

## 8. Grand but empty endings

LLM prose often rises from a local claim to “the world,” “humanity,” or “the future” without earning the scale.

| Pattern | Revision direction |
| --- | --- |
| “This is a pivotal moment for humanity.” | Give the real scope, change, and uncertainty. |
| “The journey toward X begins with Y.” | End at a useful recommendation, result, or open question. |
| “In conclusion, this shows …” | Delete repetition; add a new conclusion only if it advances the argument. |
| “综上所述” / “为我们提供了宝贵启示” | Stop at the most useful concrete point. |
